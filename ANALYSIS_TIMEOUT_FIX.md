## 🧪 ПРОВЕРКА РАБОТЫ

### Что проверить:

1. **Backend запущен:**
   ```bash
   netstat -ano | findstr :8000
   # Должен показать LISTENING на порту 8000
   ```

2. **Frontend подключается:**
   - Откройте консоль браузера
   - Должны быть логи `[API] Запрос к: http://localhost:8000/api/analyze`
   - Не должно быть ошибок `ERR_CONNECTION_REFUSED` на порт 8000

3. **Анализ завершается:**
   - Загрузите документ
   - Анализ должен завершиться в течение 5 минут
   - Если дольше - появится предупреждение, но анализ продолжится

## 📊 ОЖИДАЕМОЕ ПОВЕДЕНИЕ

### Нормальный анализ:

1. Пользователь загружает документ
2. Нажимает "Анализировать"
3. Показывается индикатор загрузки
4. Через 30 секунд - 5 минут анализ завершается
5. Показывается результат

### Если анализ долгий:

1. Через 5 минут появляется предупреждение "Анализ занимает больше времени"
2. Анализ продолжается
3. Результат показывается когда готов

### Если backend не отвечает:

1. Через 5 минут запрос прерывается
2. Показывается ошибка "Превышено время ожидания"
3. Предложение попробовать снова
