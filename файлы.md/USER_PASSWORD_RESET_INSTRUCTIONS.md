# 🔑 Инструкция для пользователей: Как сбросить пароль

## Для пользователей системы

**Пользователям не нужно ничего настраивать!** Они просто используют форму восстановления пароля в системе.

---

## 📋 Пошаговая инструкция для пользователя

### Шаг 1: Запрос сброса пароля

1. На странице входа нажмите **"Забыли пароль?"**
   - Это ссылка под полем ввода пароля

2. Введите **email**, который вы использовали при регистрации

3. Нажмите **"Отправить ссылку"**

4. Система покажет сообщение: **"Письмо отправлено"**

### Шаг 2: Проверка почты

- Проверьте **входящие** на указанном email
- Проверьте папку **"Спам"** (письмо может попасть туда)
- Письмо от: **noreply@tendershield.pro**
- Тема: **"Сброс пароля в Tender Shield Pro"**

### Шаг 3: Переход по ссылке

- Откройте письмо
- Нажмите кнопку **"Сбросить пароль"** в письме
- Или скопируйте ссылку из письма и вставьте в браузер

### Шаг 4: Установка нового пароля

1. Вы попадете на страницу установки нового пароля
2. Введите **новый пароль** (минимум 6 символов)
3. **Подтвердите пароль** (повторите новый пароль)
4. Нажмите **"Изменить пароль"**

### Шаг 5: Вход с новым паролем

- После успешной смены пароля система покажет сообщение об успехе
- Вы будете перенаправлены на страницу входа
- Войдите используя ваш **email** и **новый пароль**

---

## ⚠️ Важная информация для пользователей

### Срок действия ссылки

- Ссылка для сброса пароля действительна **30 минут**
- Если ссылка истекла, запросите новую через форму "Забыли пароль?"

### Безопасность

- Каждая ссылка может быть использована **только один раз**
- После использования ссылка становится недействительной
- Для безопасности система всегда говорит "Письмо отправлено", даже если email не найден в системе

### Если письмо не пришло

1. **Проверьте папку "Спам"** — письмо может попасть туда
2. **Подождите 1-2 минуты** — письмо может идти с задержкой
3. **Проверьте правильность email** — убедитесь, что ввели тот же email, что при регистрации
4. **Запросите новую ссылку** — если прошло больше 30 минут

### Если забыли email

Если вы не помните, какой email использовали при регистрации, свяжитесь с поддержкой системы.

## 🔧 Для администратора системы

**Чтобы функциональность работала для пользователей, необходимо:**

1. ✅ **Настроить SMTP в `backend/.env`** (см. `QUICK_EMAIL_FIX.md`)
   - Без настроенного SMTP письма не будут отправляться реально
   - Система будет работать в режиме MOCK (только логирование)

2. ✅ **Убедиться, что `TENDER_FRONTEND_URL` правильный**
   - Должен указывать на домен, где доступен фронтенд
   - Для локальной разработки: `http://localhost:5174` (или другой порт)
   - Для production: `https://ваш-домен.com`

3. ✅ **Backend должен быть запущен и доступен**

4. ✅ **База данных должна содержать таблицу `password_reset_tokens`**

## 📧 Пример письма, которое получает пользователь

```
Тема: Сброс пароля в Tender Shield Pro

Вы запросили восстановление пароля.
Если это были не вы — просто проигнорируйте письмо.

Для сброса пароля перейдите по ссылке:
[Кнопка: Сбросить пароль]

Ссылка действительна 30 минут.
Если кнопка не работает, скопируйте ссылку:
http://localhost:5174/reset-password?token=...
```

## ✅ Проверка работы функциональности

Для администратора: после настройки SMTP проверьте логи backend при запросе сброса пароля:

**Если SMTP настроен:**
```
✅ Email отправлен: user@example.com - Сброс пароля в Tender Shield Pro
✅ Письмо для сброса пароля отправлено: user@example.com
```

**Если SMTP НЕ настроен:**
```
⚠️ [MOCK EMAIL] ⚠️ SMTP не настроен, эмулируем отправку:
  To: user@example.com
  Subject: Сброс пароля в Tender Shield Pro
  💡 Для реальной отправки настройте SMTP в backend/.env
```

- **Администратору:** Настройте SMTP в `.env` файле, чтобы письма реально отправлялись
