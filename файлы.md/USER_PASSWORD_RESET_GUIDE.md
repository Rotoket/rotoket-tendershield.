# 🔑 Инструкция для пользователей: Сброс пароля

## Как пользователь может сбросить пароль

### Шаг 1: Запрос сброса пароля

1. На странице входа нажмите **"Забыли пароль?"**
2. Введите **email**, который вы использовали при регистрации
3. Нажмите **"Отправить ссылку"**

### Шаг 2: Проверьте почту

- На указанный email будет отправлена ссылка для сброса пароля
- Проверьте папку **"Входящие"** и **"Спам"**
- Ссылка действительна **30 минут**

### Шаг 3: Перейдите по ссылке

- Откройте письмо от **Tender Shield Pro**
- Нажмите на кнопку **"Сбросить пароль"** или скопируйте ссылку
- Вы будете перенаправлены на страницу установки нового пароля

### Шаг 4: Установите новый пароль

1. Введите **новый пароль** (минимум 6 символов)
2. **Подтвердите пароль** (повторите новый пароль)
3. Нажмите **"Сбросить пароль"**

### Шаг 5: Войдите с новым паролем

- После успешного сброса вы будете перенаправлены на страницу входа
- Войдите используя ваш email и **новый пароль**

---

## ⚠️ Важные моменты

### Если письмо не пришло:

1. **Проверьте папку "Спам"** - письмо может попасть туда
2. **Подождите 1-2 минуты** - письмо может идти с задержкой
3. **Проверьте, что email указан правильно** - запросите новую ссылку
4. **Ссылка действительна 30 минут** - если истекла, запросите новую

### Безопасность:

- Ссылка для сброса пароля действительна только **30 минут**
- Каждая ссылка может быть использована **только один раз**
- После использования ссылки она становится недействительной
- Для безопасности система **всегда говорит**, что письмо отправлено, даже если email не найден

### Если забыли email:

- Если вы не помните, какой email использовали при регистрации, свяжитесь с поддержкой

---

## 🔧 Для администраторов системы

Чтобы эта функциональность работала для пользователей, необходимо:

1. ✅ Настроить SMTP в `backend/.env` (см. `QUICK_EMAIL_FIX.md`)
2. ✅ Убедиться, что `TENDER_FRONTEND_URL` указывает на правильный домен
3. ✅ Backend должен быть запущен и доступен
4. ✅ База данных должна содержать таблицу `password_reset_tokens`

## 📧 Формат письма

Пользователь получит письмо со следующим содержанием:

```
Тема: Сброс пароля в Tender Shield Pro

Вы запросили восстановление пароля.
Если это были не вы — просто проигнорируйте письмо.

Для сброса пароля перейдите по ссылке:
[Кнопка: Сбросить пароль]

Ссылка действительна 30 минут.
```

## 🧪 Тестирование

Для тестирования функциональности:

1. Откройте форму входа
2. Нажмите "Забыли пароль?"
3. Введите email существующего пользователя
4. Проверьте логи backend - должно быть `✅ Email отправлен`
5. Проверьте почту (включая спам)
6. Перейдите по ссылке и установите новый пароль
