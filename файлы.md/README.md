# Tender Shield Pro
Инструмент для специалиста по тендерам: анализ документации, выявление рисков и формирование сводного дашборда.

## Цель (MVP)
- Единый экран-дашборд с блоками: «Красные флаги», «Основная информация», «Спецификации», «Сроки», «Платежи», «Гарантии», «Требования к участникам», «Нарушения закона», «Финансовая оценка», «Итоги и действия».
- Критическая информация должна быть видна сразу; подробности — в отдельных раскрывающихся блоках.
- Интерфейс только на русском языке.

## Структура репозитория
- `src/` — исходный код
- `docs/` — документация/заметки по требованиям

## Следующие шаги
- Зафиксировать формат входных данных (PDF/Docx/скан/структурированный JSON).
- Выбрать стек (web/desktop/CLI) и подход к парсингу.
- Описать правила выявления «красных флагов» и нарушений.
