# Отладка проблемы входа

## Проблема
Пользователь не может войти в систему, хотя вводит правильный логин и пароль.

## Что было исправлено

1. **Исправлены отступы в `verify_password`** - была ошибка синтаксиса
2. **Добавлено логирование** для отладки процесса авторизации
3. **Улучшена обработка ошибок** в `authenticate_user`

## Как проверить

1. Запустите backend с логированием:
   ```bash
   cd backend
   python main.py
   ```

2. Попробуйте войти через frontend

3. Проверьте логи backend - должны появиться сообщения:
   - "Попытка входа: email=..."
   - "Проверка пароля для пользователя..."
   - "✅ Успешная аутентификация" или "Неверный пароль"

## Возможные причины

1. **Пароль был захеширован другим алгоритмом** - если пользователь был создан до перехода на pbkdf2_sha256
2. **Проблема с кодировкой** - пробелы в начале/конце пароля
3. **Пользователь неактивен** - `is_active = False`

## Решение

Если проблема сохраняется:

1. Проверьте логи backend при попытке входа
2. Проверьте хеш пароля в БД - должен начинаться с `$pbkdf2-sha256$`
3. Если хеш начинается с `$2b$` (bcrypt), нужно пересоздать пользователя или мигрировать пароли

## Временное решение для тестирования

Можно создать нового пользователя через регистрацию - он будет использовать правильный алгоритм хеширования.
