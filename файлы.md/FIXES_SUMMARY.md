## ✅ 4. Сохранение анализа на 7 дней

**Что сделано:**
- Создан `frontend/src/utils/analysisStorage.ts` с функциями:
  - `saveAnalysis()` - сохраняет анализ с автоматическим сроком действия 7 дней
  - `getAllAnalyses()` - получает все валидные анализы
  - `getLastAnalysis()` - получает последний анализ для режима
  - `cleanupExpiredAnalyses()` - очищает просроченные
- Автоматическое сохранение после завершения анализа (single и package)
- Автоматическое восстановление при монтировании компонента
- Автоматическая очистка просроченных записей

**Результат:** Анализ сохраняется при переходе на другую вкладку и восстанавливается при возврате
