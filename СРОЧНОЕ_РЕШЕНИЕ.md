## 🔍 Проверка:

После перезапуска frontend:

1. Откройте консоль браузера (F12 → Console)
2. Попробуйте загрузить документ
3. В консоли вы должны увидеть:
   ```
   [API] Запрос к: http://localhost:8000/api/analyze
   [API] API_URL из env: http://localhost:8000/api
   ```

Если видите другой URL или "не установлен" - значит `.env` не подхватился.

## 📋 Если не помогло:

### Вариант 1: Проверьте .env файл вручную

Откройте файл: `frontend\.env`

Должно быть:
```
VITE_API_URL=http://localhost:8000/api
```

**Важно:** 
- Нет пробелов вокруг `=`
- Нет кавычек
- Точный формат: `VITE_API_URL=http://localhost:8000/api`

### Вариант 2: Проверьте, что backend действительно работает

Откройте в браузере: http://localhost:8000/api/health

Должен вернуться JSON:
```json
{
  "status": "ok",
  "message": "API работает",
  ...
}
```

### Вариант 3: Проверьте CORS

В консоли браузера (F12 → Console) при ошибке должно быть видно:
- Если CORS ошибка - будет сообщение про CORS
- Если "Failed to fetch" - значит backend не отвечает или неправильный URL
