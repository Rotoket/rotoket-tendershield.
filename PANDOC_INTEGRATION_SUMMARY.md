## Как это работает:

### Сценарий 1: Pandoc установлен
1. Пользователь загружает `документ.docx`
2. Система вызывает `docx_to_markdown("документ.docx")`
3. Получает Markdown с точными таблицами
4. Анализирует Markdown
5. ✅ **Результат:** Точное извлечение НМЦК, ИУН и других данных из таблиц

### Сценарий 2: Pandoc не установлен
1. Пользователь загружает `документ.docx`
2. Система пытается вызвать `docx_to_markdown()` → ошибка
3. Автоматически переходит на `Docx2txtLoader`
4. Анализирует текст (возможно, с потерей форматирования таблиц)
5. ✅ **Результат:** Анализ работает, но с ограниченной точностью

### Сценарий 3: Pandoc установлен, но файл повреждён
1. Пользователь загружает повреждённый `документ.docx`
2. Система пытается Pandoc → ошибка
3. Автоматически переходит на `Docx2txtLoader`
4. ✅ **Результат:** Анализ продолжается через fallback
