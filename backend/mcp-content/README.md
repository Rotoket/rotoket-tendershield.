# MCP Content — Справочный слой знаний

Эта папка содержит справочные материалы для MCP (Model Context Protocol) — слоя объяснений в системе Тендер.Щит.

## Структура

- **`laws/`** — справочные тексты по законам (44-ФЗ, 223-ФЗ, 209-ФЗ, 135-ФЗ)
- **`patterns/`** — типовые ситуации и формулировки в закупочной документации
- **`glossary/`** — термины для быстрого понимания директором
- **`disclaimer.md`** — обязательный дисклеймер для всех ответов

## Важные правила

✅ **Разрешено:**
- Описательные, нейтральные тексты
- Объяснения "что это значит"
- Справочная информация

❌ **Запрещено:**
- Выводы и рекомендации
- Оценка рисков
- Советы "участвовать / не участвовать"
- Слова "нарушение", "обязан", "запрещено" в императивном смысле

## Использование

MCP используется через эндпоинт `/api/legal/explain`:

```json
POST /api/legal/explain
{
  "question": "Что означает ссылка на 223-ФЗ?",
  "context": {
    "lawCode": "223-ФЗ"
  }
}
```

**ВАЖНО:** MCP НЕ влияет на Decision Engine, scoring, deal breakers или решения. Это только справочный слой для объяснений.

## Настройка

В `backend/.env`:

```env
TENDER_MCP_ENABLED=true
TENDER_MCP_CONTENT_PATH=mcp-content
```
