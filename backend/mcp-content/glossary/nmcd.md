# НМЦК / НМЦД (начальная максимальная цена контракта / договора)

НМЦК (или НМЦД) — это предельная цена контракта (договора),
выше которой участник не может подать ценовое предложение.

Обычно НМЦК используется для:
- оценки экономической целесообразности участия;
- расчёта стоимости предложения;
- определения размера обеспечения заявки и контракта;
- сравнения условий разных закупок.

Методика расчёта НМЦК может отличаться
в зависимости от режима закупки и внутренних документов заказчика.
