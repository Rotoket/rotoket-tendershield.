# 🔍 Диагностика проблемы анализа документов

## Проблема
Анализ документов возвращает ошибку 500.

## Возможные причины

### 1. Проблема с Ollama
- ✅ Ollama доступен (проверено)
- ✅ Модель qwen2.5:0.5b установлена
- ⚠️ Возможна проблема с вызовом LLM

### 2. Проблема с парсингом JSON
- LLM может возвращать невалидный JSON
- Нужна обработка ошибок парсинга

### 3. Проблема с чтением файла
- Ошибка при чтении DOC/DOCX
- Проблема с кодировкой

### 4. Проблема с БД
- Ошибка при сохранении результата
- Проблема с транзакциями

## Решение

Проверьте логи backend при запуске анализа для точной диагностики.
