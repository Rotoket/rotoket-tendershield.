# 🔍 Инструкция по диагностике проблемы анализа

## Если анализ не работает (ошибка 500)

### Шаг 1: Проверьте, что backend запущен

```bash
cd backend
venv\Scripts\activate
uvicorn main:app --reload --log-level info
```

Должны увидеть:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

### Шаг 2: Попробуйте проанализировать документ

Через фронтенд или через API:
```bash
curl -X POST "http://localhost:8000/api/analyze" \
  -F "file=@test.pdf" \
  -F "industry=UNIVERSAL"
```

### Шаг 3: Проверьте логи backend

В консоли, где запущен backend, должны быть логи:
- `--- АНАЛИЗ ДОКУМЕНТА: filename [industry] ---`
- `Отправка в Ollama (модель: qwen2.5:0.5b)...`
- Или ошибки с деталями

### Шаг 4: Проверьте Ollama (опционально)

```bash
# Проверка доступности
curl http://localhost:11434/api/tags

# Проверка модели
ollama list
```

Если Ollama недоступен, система использует fallback-анализ.

## Если проблема сохраняется

1. **Запустите backend с детальным логированием:**
```bash
uvicorn main:app --reload --log-level debug
```

2. **Попробуйте проанализировать документ**

3. **Скопируйте логи из консоли** - там будет точная причина ошибки

4. **Проверьте:**
   - Формат файла (PDF, DOCX, DOC, TXT)
   - Размер файла (макс. 50 МБ)
   - Что backend действительно запущен

## Типичные ошибки

1. **"Internal Server Error"** - проверьте логи backend
2. **"Ollama недоступен"** - но есть fallback, должен работать
3. **"Файл не читается"** - проверьте формат файла
4. **"Достигнут лимит"** - проверьте тариф пользователя
