# 🔧 Исправление ошибки регистрации

## Проблема
При регистрации нового пользователя возникает ошибка: "Ошибка при регистрации пользователя"

## Причина
В базе данных отсутствуют новые поля для системы триалов, которые были добавлены в модель `User`:
- `plan_type`
- `trial_start`
- `trial_end`
- `trial_extended`
- `subscription_start`
- `subscription_end`

## Решение

### Вариант 1: Автоматическая миграция (рекомендуется)

Выполните скрипт миграции:

```bash
cd backend
python migrate_trial_fields.py
```

Скрипт автоматически проверит наличие полей и добавит их, если они отсутствуют.

### Вариант 2: Ручная миграция через SQL

Если у вас PostgreSQL:

```sql
ALTER TABLE users ADD COLUMN IF NOT EXISTS plan_type VARCHAR DEFAULT 'trial';
ALTER TABLE users ADD COLUMN IF NOT EXISTS trial_start TIMESTAMP;
ALTER TABLE users ADD COLUMN IF NOT EXISTS trial_end TIMESTAMP;
ALTER TABLE users ADD COLUMN IF NOT EXISTS trial_extended BOOLEAN DEFAULT FALSE;
ALTER TABLE users ADD COLUMN IF NOT EXISTS subscription_start TIMESTAMP;
ALTER TABLE users ADD COLUMN IF NOT EXISTS subscription_end TIMESTAMP;
```

Если у вас SQLite (без IF NOT EXISTS):

```sql
ALTER TABLE users ADD COLUMN plan_type VARCHAR DEFAULT 'trial';
ALTER TABLE users ADD COLUMN trial_start TIMESTAMP;
ALTER TABLE users ADD COLUMN trial_end TIMESTAMP;
ALTER TABLE users ADD COLUMN trial_extended BOOLEAN DEFAULT 0;
ALTER TABLE users ADD COLUMN subscription_start TIMESTAMP;
ALTER TABLE users ADD COLUMN subscription_end TIMESTAMP;
```

### Вариант 3: Пересоздание таблиц (только для разработки!)

⚠️ **ВНИМАНИЕ:** Это удалит все данные!

```python
# В Python консоли или скрипте
from database import Base, engine
Base.metadata.drop_all(bind=engine)
Base.metadata.create_all(bind=engine)
```

Затем выполните:
```bash
python init_db.py
```

## Проверка

После миграции проверьте, что поля добавлены:

```sql
-- PostgreSQL
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'users' 
AND column_name IN ('plan_type', 'trial_start', 'trial_end');

-- SQLite
PRAGMA table_info(users);
```

## Что было исправлено в коде

1. ✅ Добавлена проверка наличия полей триалов перед их использованием
2. ✅ Улучшена обработка ошибок с детальным логированием
3. ✅ Код работает как со старыми таблицами (без полей триалов), так и с новыми

## После миграции

После выполнения миграции регистрация должна работать корректно:
- Новые пользователи автоматически получают триал на 14 дней
- Информация о триале сохраняется в БД
- Профиль пользователя показывает оставшиеся дни триала

## Если проблема сохраняется

1. Проверьте логи сервера - там должна быть детальная информация об ошибке
2. Убедитесь, что БД подключена и доступна
3. Проверьте, что все зависимости установлены: `pip install -r requirements.txt`
4. Убедитесь, что таблица `users` существует: `SELECT * FROM users LIMIT 1;`
