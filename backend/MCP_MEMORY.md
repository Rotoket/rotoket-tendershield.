# backend/.mcp-memory.json

`backend/.mcp-memory.json` — это data-файл проекта (справочник/память), а не конфиг MCP-серверов.

## Что внутри
Типовые сущности:
- шаблоны рисков (severity, описание, рекомендация)
- категории (financial/legal/it/…)
- ключевые слова для матчинг-логики
- метаданные (version, source, stored_at)

## Зачем это нужно
- стандартизировать формулировки «красных флагов»
- ускорить генерацию отчётов и рекомендаций
- обеспечить повторяемость результатов (одинаковые входы → похожие выходы)

## Правила изменения
- Не добавлять секреты и персональные данные.
- Держать ключи стабильными (если ключ поменять — может сломаться маппинг в коде).
- Для крупных правок: сначала добавить новый ключ, потом (если нужно) сделать миграцию/совместимость в коде.

## Если понадобится переименование файла
Если захотим переименовать файл во что-то менее похожее на конфиг (например `backend/risk_memory.json`), сначала нужно проверить реальные импорты в коде и сделать замену путей там.
