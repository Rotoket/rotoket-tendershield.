
### Вариант 2: Запуск через Batch файл

Дважды щелкните на файл: **start-all.bat**

**Терминал 1 - Backend:**
```powershell
cd C:\Users\Dom\Desktop\tender-shield-pro\backend

```

**Терминал 2 - Frontend:**
```powershell

npm run dev
```
