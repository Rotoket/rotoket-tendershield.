## 📝 Что логируется

### TenderAnalysis:
- Режим работы (single/package)
- Параметры загруженных файлов
- Результаты анализа (verdict, score, issues, deal_breakers, financial_analysis, smart_questions)
- Ошибки анализа
- Загрузка правовых ссылок

### DocumentGenerator:
- Наличие initialData
- Количество dealBreakers и smartQuestions
- Автоматическое открытие протокола

### RiskNarrative:
- Количество рисков и dealBreakers
- Наличие обработчиков событий
- Клики по кнопкам

---

## 🚀 Использование

1. Запустите локальный сервер отладки на порту 7242
2. Откройте приложение в браузере
3. Выполните действия (загрузка файлов, анализ, генерация документов)
4. Данные будут автоматически отправляться на сервер отладки

---

## ⚠️ Примечания

- Логирование выполняется асинхронно через `fetch`
- Ошибки сети игнорируются (`.catch(() => {})`)
- Не влияет на работу приложения
- Можно отключить, удалив вызовы `debugLog()`
