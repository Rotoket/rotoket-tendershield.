# UI CANON — Тендер.Щит (НЕ ИЗМЕНЯТЬ)

Данный документ является КАНОНОМ UI для системы «Тендер.Щит».
Это не руководство по дизайну, а архитектурный контракт.
Любые отклонения, улучшения, перефразирования или инициативы запрещены.

## ОСНОВНОЙ КАНОН СИСТЕМЫ

1. Система никогда не дает рекомендаций.
   Запрещены слова и смыслы: «советуем», «лучше», «рекомендуем», «оптимально».

2. Система работает по Evidence-first принципу.
   Только факты, цитаты и зафиксированные условия.
   Никаких интерпретаций «от себя».

3. Управленческое решение всегда принимает и фиксирует человек.
   Система не подменяет волю директора.

4. Все действия и решения фиксируются в неизменяемом Audit Trail
   (append-only, юридически значимый след).

## MAIN SCREEN MANIFEST (ГЛАВНЫЙ ЭКРАН)

Главный экран — это вход в управленческую ответственность, а не в аналитику.

Обязательные принципы:
- Экран должен сразу читаться директором за 5–10 секунд.
- Экран не втягивает в анализ.
- Экран разделяет роли: Директор / Эксперт.

### CTA-КОНТРАКТ (СТРОГО)

Допустимы ТОЛЬКО два CTA:
1. «Инициировать анализ» — для Эксперта
2. «Журнал управленческих решений» — для Директора

Запрещено:
- универсальные CTA («Начать», «Попробовать»)
- CTA, ведущие напрямую в аналитику

### СМЫСЛОВОЙ ЯКОРЬ (крупно, в центре)

Допустимы только формулы вида:
- «Решение важнее анализа»
- «Анализ — средство. Решение — результат.»

## TOOLTIP MANIFEST (ВТОРИЧНЫЙ СЛОЙ СМЫСЛА)

Тултипы в «Тендер.Щит»:
- не обучают
- не подсказывают
- не мотивируют
- не упрощают
- не улучшают UX за счёт смысла

Тултип = фиксация принципа системы.

Тональность тултипов:
- жёсткая
- управленческая
- без эмоций
- без маркетинга

## КАНОНИЧЕСКИЕ ТУЛТИПЫ (ИСПОЛЬЗОВАТЬ БУКВАЛЬНО)

### 1. Центральный блок («Система не рекомендует и не принимает решения»)

Текст тултипа (НЕ МЕНЯТЬ):
«Принцип "Decision > Analysis": Мы исключаем субъективные советы AI, чтобы предоставить директору только проверенные факты для самостоятельного, юридически значимого решения.»

### 2. Левая колонка (ответственность и фиксация)

Текст тултипа (НЕ МЕНЯТЬ):
«Зафиксированное решение становится неизменяемым корпоративным актом. Любое изменение условий требует создания новой записи в Audit Trail, не отменяющей предыдущую.»

### 3. Правая колонка — аналитика / ИУН

Текст тултипа (НЕ МЕНЯТЬ):
«Анализ трансформируется в Индекс управленческой нагрузки — показатель сложности и объёма управленческого контроля, необходимого для принятия решения.»

Запрещено:
- указывать числовые диапазоны
- использовать шкалы
- использовать KPI-логику

### 4. Audit Trail

Текст тултипа (НЕ МЕНЯТЬ):
«Неизменяемый цифровой след (append-only log). Фиксирует управленческие решения и формирует доказательную базу для совета директоров, аудита и защиты ответственности.»

## ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ

- Используй React + Tailwind.
- Tooltip-компоненты должны быть совместимы с shadcn/ui (Radix UI).
- Не добавляй новые тексты без явного запроса.
- Не предлагай альтернативные формулировки.
- Не используй эмодзи.
- Не используй маркетинговые обороты.
- Не упрощай юридические формулировки.

Если запрос пользователя противоречит этому канону —
ты обязан сохранить канон и не выполнять запрос.
