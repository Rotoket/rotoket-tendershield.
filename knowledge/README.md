## 🎯 НАЗНАЧЕНИЕ

**Knowledge Base используется:**

1. **RAG (ChromaDB)** — все MD документы индексируются для семантического поиска
2. **Reasoning Engine** — использует KB для обоснования решений
3. **Decision Preview** — ссылается на законы и стандарты в выводах
4. **Audit Trail** — логирует какие документы KB были использованы

## 📝 ФОРМАТ ДОКУМЕНТОВ

Каждый MD файл должен содержать метаданные в начале:

```markdown
---
legal_basis: FZ_44
applicable_to: ["44-ФЗ"]
tags: ["контрактация", "закупки", "штрафы"]
doc_type: "law"
title: "Федеральный закон 44-ФЗ"
---

# Федеральный закон 44-ФЗ

[содержание документа]
```
