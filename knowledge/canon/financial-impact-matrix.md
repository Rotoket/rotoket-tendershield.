# 💰 МАТРИЦА ФИНАНСОВОГО ВЛИЯНИЯ

**Каноническая матрица расчета финансового влияния рисков на решение об участии в закупке**

---

## 📊 ОСНОВНЫЕ ПАРАМЕТРЫ

### 1. Best Case (лучший сценарий)

**Формула:**
```
Best Case = НМЦК 
          - Затраты на производство/закупку
          - Затраты на митигацию DEALBREAKER
          - Затраты на митигацию CONTROLLED RISK
          - Затраты на логистику
          - Затраты на обеспечение
          + Маржа
```

**Пример:**
- НМЦК: 5,000,000 руб.
- Затраты: 3,000,000 руб.
- Митигация DEALBREAKER: 200,000 руб. (пропуск + сертификат)
- Логистика: 100,000 руб.
- Обеспечение: 500,000 руб. (10% от НМЦК)
- **Best Case:** 5,000,000 - 3,000,000 - 200,000 - 100,000 - 500,000 = **1,200,000 руб.**

---

### 2. Worst Case (худший сценарий)

**Формула:**
```
Worst Case = НМЦК 
           - Затраты на производство/закупку
           - Затраты на митигацию DEALBREAKER
           - Затраты на митигацию CONTROLLED RISK
           - Затраты на логистику
           - Затраты на обеспечение
           - Штрафы за нарушение срока (10% от НМЦК для 44-ФЗ)
           - Неустойки за неисполнение
           - Дополнительные затраты на устранение проблем
```

**Пример:**
- НМЦК: 5,000,000 руб.
- Затраты: 3,000,000 руб.
- Митигация DEALBREAKER: 200,000 руб.
- Логистика: 100,000 руб.
- Обеспечение: 500,000 руб.
- Штраф за просрочку: 500,000 руб. (10% от НМЦК)
- **Worst Case:** 5,000,000 - 3,000,000 - 200,000 - 100,000 - 500,000 - 500,000 = **700,000 руб.**

---

### 3. Expected Value (ожидаемое значение)

**Формула:**
```
Expected Value = Best Case × (1 - P) + Worst Case × P

где P = вероятность Worst Case (0.0 - 1.0)
```

**Пример:**
- Best Case: 1,200,000 руб.
- Worst Case: 700,000 руб.
- Вероятность Worst Case: 20% (0.2)
- **Expected Value:** 1,200,000 × 0.8 + 700,000 × 0.2 = **1,100,000 руб.**

## 🎯 ПРИНЯТИЕ РЕШЕНИЯ НА ОСНОВЕ ФИНАНСОВ

### Правило 1: Expected Value > 0

**Если Expected Value > 0:**
- → **VERDICT:** `PROCEED` или `PROCEED_WITH_CONDITIONS`
- → **Обоснование:** Ожидаемая прибыль положительна

**Если Expected Value < 0:**
- → **VERDICT:** `DO_NOT_PARTICIPATE` или `POSTPONE`
- → **Обоснование:** Ожидаемая прибыль отрицательна

---

### Правило 2: Best Case > 20% маржи

**Если Best Case > 20% маржи:**
- → **VERDICT:** `PROCEED` или `PROCEED_WITH_CONDITIONS`
- → **Обоснование:** Хорошая маржа в лучшем случае

**Если Best Case < 20% маржи:**
- → **VERDICT:** `POSTPONE` или `DO_NOT_PARTICIPATE`
- → **Обоснование:** Низкая маржа даже в лучшем случае

---

### Правило 3: Worst Case > 0

**Если Worst Case > 0:**
- → **VERDICT:** `PROCEED` или `PROCEED_WITH_CONDITIONS`
- → **Обоснование:** Даже в худшем случае есть прибыль

**Если Worst Case < 0:**
- → **VERDICT:** `DO_NOT_PARTICIPATE` или `POSTPONE`
- → **Обоснование:** В худшем случае убыток

## ✅ ИСПОЛЬЗОВАНИЕ В СИСТЕМЕ

**При анализе контракта:**
- Система рассчитывает Best Case, Worst Case, Expected Value
- Определяет вероятность Worst Case на основе рисков
- Принимает решение на основе матрицы решений
- Отображает финансовое влияние в Decision Preview

**В Decision Preview:**
- Best Case отображается зеленым
- Worst Case отображается красным
- Expected Value отображается как основной показатель
- Вероятность Worst Case отображается как процент

---

**Использование в системе:**
- ProcurementReasoningEngine использует эту матрицу для расчета финансового влияния
- Decision Preview отображает финансовые показатели
- Financial Impact Chart визуализирует Best/Worst Case
