# ✅ ЧЕКЛИСТ ПОДАЧИ ЗАЯВКИ НА УЧАСТИЕ В ЗАКУПКЕ

**Универсальный чеклист для проверки готовности к участию в закупке (44-ФЗ и 223-ФЗ)**

---

## 📋 ЭТАП 1: АНАЛИЗ ДОКУМЕНТАЦИИ (До подачи заявки)

### 1.1 Проверка правового режима
- [ ] Определен режим закупки: 44-ФЗ / 223-ФЗ / иное
- [ ] Проверено соответствие документации выбранному режиму
- [ ] Выявлены нарушения требований закона (если есть)

### 1.2 Анализ предмета закупки
- [ ] Предмет закупки понятен и соответствует возможностям компании
- [ ] Технические требования выполнимы
- [ ] Нет необоснованных требований к товарным знакам
- [ ] Требования соответствуют 135-ФЗ (защита конкуренции)

### 1.3 Анализ финансовых условий
- [ ] НМЦК указана и обоснована
- [ ] Цена контракта приемлема (есть маржа)
- [ ] Условия оплаты приемлемы (сроки, аванс)
- [ ] Размер обеспечения приемлем (5-30% для 44-ФЗ)
- [ ] Штрафы не превышают нормы (10% для 44-ФЗ)

### 1.4 Анализ сроков
- [ ] Сроки подачи заявок соответствуют требованиям закона
- [ ] Сроки поставки/выполнения реалистичны
- [ ] Есть запас времени на подготовку

### 1.5 Анализ требований к участнику
- [ ] Опыт выполнения аналогичных контрактов (≥20% от НМЦК для 44-ФЗ)
- [ ] Наличие необходимых лицензий
- [ ] Наличие необходимых сертификатов (ТР ЕАЭС, СанПиН и т.д.)
- [ ] Отсутствие ограничений участия

### 1.6 Анализ рисков
- [ ] Выявлены DEALBREAKER (критичные блокеры)
- [ ] Выявлены CONTROLLED RISK (управляемые риски)
- [ ] Оценено финансовое влияние рисков
- [ ] Принято решение: PROCEED / PROCEED_WITH_CONDITIONS / DO_NOT / POSTPONE

---

## 📋 ЭТАП 2: ПОДГОТОВКА ДОКУМЕНТОВ (За 1-2 недели до дедлайна)

### 2.1 Документы для заявки
- [ ] Заявка на участие заполнена
- [ ] Техническая часть заявки подготовлена
- [ ] Коммерческая часть заявки подготовлена
- [ ] Документы подтверждающие соответствие требованиям

### 2.2 Документы подтверждающие опыт
- [ ] Копии контрактов на сумму ≥20% от НМЦК (для 44-ФЗ)
- [ ] Акт выполненных работ / оказанных услуг
- [ ] Документы подтверждающие опыт в нужной сфере

### 2.3 Документы подтверждающие квалификацию
- [ ] Лицензии (если требуются)
- [ ] Сертификаты (ТР ЕАЭС, СанПиН и т.д.)
- [ ] СРО допуск (для строительных работ)
- [ ] Другие документы согласно требованиям

### 2.4 Документы подтверждающие финансовое состояние
- [ ] Выписка из ЕГРЮЛ (не старше 6 месяцев)
- [ ] Бухгалтерская отчетность (если требуется)
- [ ] Справка об отсутствии задолженности (если требуется)

### 2.5 Документы для обеспечения заявки
- [ ] Деньги на счете для обеспечения заявки (0.5-5% от НМЦК)
- [ ] Или банковская гарантия для обеспечения заявки

---

## 📋 ЭТАП 3: ПОДАЧА ЗАЯВКИ (В день дедлайна)

### 3.1 Проверка перед подачей
- [ ] Все документы подготовлены и проверены
- [ ] Заявка заполнена полностью
- [ ] Все обязательные поля заполнены
- [ ] Нет ошибок в данных

### 3.2 Подача заявки
- [ ] Заявка подана в ЕИС (для 44-ФЗ) или на площадке заказчика (для 223-ФЗ)
- [ ] Обеспечение заявки внесено (до окончания срока подачи)
- [ ] Получено подтверждение о принятии заявки

### 3.3 После подачи
- [ ] Сохранена копия заявки
- [ ] Сохранены все документы
- [ ] Отслеживается статус заявки в ЕИС / на площадке

---

## 📋 ЭТАП 4: РАССМОТРЕНИЕ ЗАЯВОК (После дедлайна)

### 4.1 Мониторинг процедуры
- [ ] Проверяется протокол рассмотрения заявок
- [ ] Проверяется протокол определения победителя
- [ ] Проверяется отсутствие нарушений

### 4.2 Если заявка отклонена
- [ ] Изучены причины отклонения
- [ ] Оценена возможность обжалования в ФАС
- [ ] Принято решение об обжаловании (если есть нарушения)

### 4.3 Если признаны победителем
- [ ] Получен проект контракта
- [ ] Проверен проект контракта на соответствие документации
- [ ] Подготовлено обеспечение исполнения контракта (5-30% от НМЦК)
- [ ] Подписан контракт в установленные сроки

---

## 📋 ЭТАП 5: ИСПОЛНЕНИЕ КОНТРАКТА (После заключения)

### 5.1 Подготовка к исполнению
- [ ] Организована логистика (если требуется)
- [ ] Подготовлены документы для поставки/выполнения
- [ ] Проверено соответствие товара/работ требованиям

### 5.2 Исполнение контракта
- [ ] Соблюдены сроки поставки/выполнения
- [ ] Соблюдены требования к качеству
- [ ] Подготовлены документы для приемки

### 5.3 Приемка и оплата
- [ ] Товар/работы приняты заказчиком
- [ ] Получены документы о приемке
- [ ] Оплата произведена в установленные сроки
- [ ] Обеспечение возвращено (после исполнения)

---

## ⚠️ КРИТИЧНЫЕ МОМЕНТЫ

**Нельзя пропустить:**
1. **Сроки подачи заявок** — нельзя пропустить дедлайн
2. **Обеспечение заявки** — должно быть внесено до окончания срока
3. **Подписание контракта** — в течение 5 дней после определения победителя (для 44-ФЗ)
4. **Сроки поставки** — нарушение → штраф 10% от цены (для 44-ФЗ)

- **44-ФЗ, ст. 44** — Сроки подачи заявок

- **223-ФЗ** — Требования определяются Положением о закупках

---

**Использование в системе:**
- При анализе контракта система генерирует персонализированный чеклист
- Каждый пункт связан с конкретными evidence из анализа
- Чеклист включает дедлайны и стоимость каждого действия
