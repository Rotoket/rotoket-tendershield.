# ✅ Решение ошибки "Failed to fetch"

## 🔴 Проблема
При анализе документов появляется ошибка подключения к серверу.

## ✅ Решение (2 минуты)

### 1️⃣ Запустите Backend сервер

**Откройте новый терминал PowerShell** и выполните:

```powershell
cd C:\Users\Dom\Desktop\tender-shield-pro\backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**✅ Успех:** Вы увидите:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

**⚠️ ВАЖНО:** Оставьте этот терминал открытым! Backend должен работать постоянно.

### 2️⃣ Проверьте Frontend

Убедитесь, что frontend запущен. Если нет, откройте **еще один терминал**:

```powershell
cd C:\Users\Dom\Desktop\tender-shield-pro\frontend
npm run dev
```

### 3️⃣ Проверьте подключение

Откройте в браузере: **http://localhost:8000/api/health**

Должен вернуться JSON с `"status": "ok"`

## 📋 Что проверить

✅ **Backend запущен?**
```powershell
netstat -ano | findstr ":8000"
```
Должен показать процесс на порту 8000

✅ **Frontend запущен?**
```powershell
netstat -ano | findstr ":5173"
```
Должен показать процесс на порту 5173

✅ **Файл .env настроен?**
Файл `frontend\.env` должен содержать:
```
VITE_API_URL=http://localhost:8000/api
```
(✅ Уже настроен правильно!)

## ⚠️ Если не помогло

1. **Перезапустите оба сервиса:**
   - Остановите backend (Ctrl+C)
   - Остановите frontend (Ctrl+C)
   - Запустите заново

2. **Проверьте консоль браузера (F12):**
   - Откройте вкладку Console
   - Посмотрите детальные ошибки
   - Проверьте вкладку Network для просмотра запросов

3. **Проверьте логи backend:**
   - В терминале backend должны быть логи запросов
   - Если ошибок нет, значит backend работает

---

**После запуска backend ошибка должна исчезнуть!** 🎉
