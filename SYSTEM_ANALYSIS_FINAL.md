## 🔧 ИСПРАВЛЕННЫЕ ОШИБКИ

### 1. NameError: переменная llm_passport

**Проблема:**
```python
# Строка 3167: использование llm_passport вне области видимости
extraction_method="llm" if llm_passport and llm_passport.get("nmck_numeric") else "regex"
```

**Исправление:**
```python
# Добавлена инициализация перед блоком try-except
llm_passport = None  # Инициализируем для использования в дальнейшем коде
try:
    llm_passport = ai_data.get("tender_passport", {})
    # ...
except Exception as passport_error:
    llm_passport = None
```

**Файл:** `backend/main.py` (строка 2824)

---

### 2. Обработка пустых quote

**Проблема:**
- Если `quote` пустой, могла быть ошибка валидации Pydantic
- `TenderSource` требует обязательное поле `quote`

**Исправление:**
```python
# Было:
quote=tender_passport_data.get("nmck_source", "")[:500]

# Стало:
nmck_quote = tender_passport_data.get("nmck_source", "") or ""
quote=nmck_quote[:500] if nmck_quote else "Извлечено из документа"
```

**Файл:** `backend/main.py` (строки 3166-3205)

---

### 3. Обработка None значений

**Проблема:**
- Если `nmck_source` это None, то `.get("quote")` вызывал AttributeError

**Исправление:**
```python
# Используется безопасный доступ с fallback
regex_passport.get("nmck_source", {}).get("quote", "")
```

**Файл:** `backend/main.py` (строки 2843-2851)
