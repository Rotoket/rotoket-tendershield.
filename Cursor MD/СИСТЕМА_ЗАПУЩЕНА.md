## ⚠️ Если сервисы не работают

Возможно, фоновый запуск не сработал. Запустите вручную:

### Терминал 1 - Backend:

```powershell
cd C:\Users\Dom\Desktop\tender-shield-pro\backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Вы должны увидеть:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### Терминал 2 - Frontend:

Откройте **НОВЫЙ терминал** и выполните:

```powershell
cd C:\Users\Dom\Desktop\tender-shield-pro\frontend
npm run dev
```

Вы должны увидеть:
```
  Local:   http://localhost:5173/
```

## 🛑 Остановка

Нажмите `Ctrl + C` в каждом терминале для остановки.

## 📊 Проверка процессов

### Посмотреть запущенные процессы:

```powershell
# Python (backend)
Get-Process python

# Node (frontend)
Get-Process node

# Проверка портов
netstat -ano | findstr ":8000"
netstat -ano | findstr ":5173"
```

### Остановить все процессы:

```powershell
# Backend
Get-Process python -ErrorAction SilentlyContinue | Stop-Process -Force

# Frontend
Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
```
