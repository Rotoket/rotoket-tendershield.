## 🔍 Текущая проблема:

**Ошибка:** `unable to allocate CUDA0 buffer` - проблема с памятью GPU

### Решения:

#### Вариант 1: Использовать более легкую модель
```bash
# Установите легкую модель
ollama pull qwen2.5:0.5b

# Измените в config.py или .env:
OLLAMA_MODEL=qwen2.5:0.5b
```

#### Вариант 2: Использовать CPU режим
```bash
# Установите переменную окружения перед запуском Ollama
set OLLAMA_NUM_GPU=0
# или в Linux/Mac:
export OLLAMA_NUM_GPU=0
```

#### Вариант 3: Освободить память GPU
- Закройте другие приложения, использующие GPU
- Перезапустите Ollama

## 📝 Настройка модели:

### В файле `.env`:
```env
TENDER_OLLAMA_BASE_URL=http://localhost:11434
TENDER_OLLAMA_MODEL=qwen2.5-coder:7b
```

### Или в `config.py`:
```python
OLLAMA_MODEL: str = "qwen2.5-coder:7b"  # или "qwen2.5:0.5b" для слабых систем
```
