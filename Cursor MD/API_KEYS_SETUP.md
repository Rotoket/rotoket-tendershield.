# 🔑 Руководство по получению API-ключей для TenderShield

Этот документ содержит пошаговые инструкции для получения всех необходимых API-ключей и настройки внешних сервисов для работы TenderShield.

---

## 📋 Список необходимых ключей

Для полноценной работы TenderShield вам понадобятся:

1. ✅ **YooKassa (Yandex Kassa)** — для приёма платежей от пользователей
2. ✅ **SMTP (Gmail/почтовый сервис)** — для отправки email-уведомлений
3. ✅ **JWT Secret Key** — для безопасности (генерируется самостоятельно)
4. ⚠️ **Опционально: Redis** — для кеширования (можно без него)

---

## 1. 💳 YooKassa (Yandex Kassa) — Приём платежей

### Что это?
YooKassa — платёжная система от Яндекса для приёма платежей в России. Используется для оплаты подписок пользователями.

### Пошаговая инструкция получения ключей:

#### Шаг 1: Регистрация в Яндекс.Кассе
1. Перейдите на сайт: **https://yookassa.ru/**
2. Нажмите кнопку **"Подключиться"** или **"Войти"**
3. Войдите через аккаунт Яндекса (если нет — создайте)

#### Шаг 2: Создание магазина
1. После входа перейдите в **"Мой магазин"** → **"Добавить магазин"**
2. Заполните данные:
   - Название магазина: `TenderShield Pro`
   - Сайт магазина: `https://tendershield.pro` (или ваш домен)
   - Категория: `Услуги` → `Консалтинг` или `Программное обеспечение`
   - Описание: `AI-система для анализа тендерной документации`

#### Шаг 3: Получение ключей
1. После создания магазина откройте его в личном кабинете
2. Перейдите в раздел **"Настройки"** → **"API"**
3. Вы увидите два ключа:
   - **Shop ID** (ID магазина) — например: `123456`
   - **Секретный ключ** — например: `live_ABCD1234EFGH5678IJKL9012MNOP3456`

#### Шаг 4: Тестовый режим (для разработки)
1. В разделе **"Настройки"** → **"API"** включите **"Тестовый режим"**
2. Скопируйте **тестовые ключи** (они будут отличаться от боевых)
   - **Тестовый Shop ID**
   - **Тестовый секретный ключ** (начинается с `test_...`)

#### Шаг 5: Настройка Webhook (для уведомлений о платежах)
1. В разделе **"Настройки"** → **"Webhook"**
2. Укажите URL: `https://ваш-домен.ru/api/payment/webhook`
3. Выберите события для отправки:
   - ✅ `payment.succeeded` — платёж успешно выполнен
   - ✅ `payment.canceled` — платёж отменён

**⚠️ Важно:** Webhook работает только на HTTPS-доменах. В тестовом режиме можно использовать локальный туннель (ngrok).

## 2. 📧 SMTP (Gmail) — Отправка email

### Что это?
SMTP — протокол для отправки email-уведомлений пользователям (регистрация, восстановление пароля, уведомления о платежах).

### Пошаговая инструкция (Gmail):

#### Вариант A: Gmail (рекомендуется для начала)

**Шаг 1: Подготовка аккаунта Gmail**
1. Используйте существующий Gmail-аккаунт или создайте новый (например: `noreply.tendershield@gmail.com`)
2. ⚠️ **Важно:** Включите двухфакторную аутентификацию (2FA) в настройках аккаунта Google

**Шаг 2: Создание пароля приложения**
1. Перейдите на: **https://myaccount.google.com/security**
2. Прокрутите до раздела **"Двухэтапная аутентификация"** и убедитесь, что она включена
3. Перейдите в **"Пароли приложений"** (может быть в разделе "2-Step Verification")
4. Выберите:
   - **Приложение:** `Почта`
   - **Устройство:** `Другое (название)` → введите: `TenderShield Server`
5. Нажмите **"Создать"**
6. **Скопируйте 16-символьный пароль** (например: `abcd efgh ijkl mnop`) — сохраните его!

**Шаг 3: Настройка в проекте**
- **SMTP_HOST:** `smtp.gmail.com`
- **SMTP_PORT:** `587`
- **SMTP_USER:** ваш email (например: `noreply.tendershield@gmail.com`)
- **SMTP_PASSWORD:** пароль приложения (16 символов, без пробелов: `abcdefghijklmnop`)
- **SMTP_FROM:** `noreply@tendershield.pro` (или ваш email)

#### Вариант B: Альтернативные почтовые сервисы

**Mail.ru:**
- SMTP_HOST: `smtp.mail.ru`
- SMTP_PORT: `465` (SSL) или `587` (TLS)
- SMTP_USER: ваш email на Mail.ru
- SMTP_PASSWORD: пароль приложения (создаётся аналогично Gmail)

**Yandex Mail:**
- SMTP_HOST: `smtp.yandex.ru`
- SMTP_PORT: `465` (SSL) или `587` (TLS)
- SMTP_USER: ваш email на Yandex
- SMTP_PASSWORD: пароль приложения (настройки → Пароли и доступ)

**SendGrid / Mailgun (для продакшена):**
- Регистрация на sendgrid.com или mailgun.com
- Получение API-ключа в панели управления
- Использование SMTP-настроек из документации сервиса

## 3. 🔐 JWT Secret Key — Ключ безопасности

### Что это?
JWT Secret Key используется для подписи токенов авторизации. Это критически важный ключ для безопасности!

### Генерация ключа:

#### Вариант A: Онлайн-генератор (быстро)
1. Перейдите на: **https://www.lastpass.com/features/password-generator**
2. Установите:
   - Длина: **64 символа**
   - Включить цифры, буквы, символы
3. Скопируйте сгенерированный ключ

#### Вариант B: Python-скрипт (надежно)
```python
import secrets
print(secrets.token_urlsafe(64))
```

#### Вариант C: PowerShell (Windows)
```powershell
-join ((48..57) + (65..90) + (97..122) + (33,35,36,37,38,40,41,42,43,45,61,63,64) | Get-Random -Count 64 | % {[char]$_})
```

**⚠️ Важно:**
- Длина ключа должна быть **минимум 32 символа** (лучше 64+)
- Используйте случайные символы (буквы, цифры, спецсимволы)
- **Никогда не публикуйте этот ключ в GitHub!**
- В продакшене используйте разные ключи для разных окружений

## 5. ✅ Проверка настроек

### Проверка YooKassa:

```python
# В Python-консоли или тестовом скрипте
from yookassa import Configuration, Payment
Configuration.account_id = "ваш_shop_id"
Configuration.secret_key = "ваш_секретный_ключ"

# Попытка создать тестовый платёж
payment = Payment.create({
    "amount": {"value": "1.00", "currency": "RUB"},
    "confirmation": {"type": "redirect", "return_url": "https://example.com"},
    "description": "Тест"
})

print("✅ YooKassa работает! Payment ID:", payment.id)
```

### Проверка SMTP:
```python
# Тестовый скрипт backend/test_smtp.py
import smtplib
from email.mime.text import MIMEText

smtp_host = "smtp.gmail.com"
smtp_port = 587
smtp_user = "ваш_email@gmail.com"
smtp_password = "ваш_пароль_приложения"

try:
    server = smtplib.SMTP(smtp_host, smtp_port)
    server.starttls()
    server.login(smtp_user, smtp_password)
    
    msg = MIMEText("Тестовое сообщение")
    msg["Subject"] = "Тест TenderShield"
    msg["From"] = smtp_user
    msg["To"] = "тестовый_email@example.com"
    
    server.send_message(msg)
    server.quit()
    print("✅ Email отправлен успешно!")
except Exception as e:
    print(f"❌ Ошибка: {e}")
```

## 6. 🔒 Безопасность

### ✅ Обязательные правила:

1. **Никогда не коммитьте `.env` в Git!**
   - Файл уже добавлен в `.gitignore`
   - Проверьте: `git status` не должен показывать `.env`

2. **Используйте разные ключи для разных окружений:**
   - Тестовый сервер → тестовые ключи
   - Продакшен → боевые ключи

3. **Регулярно ротируйте ключи:**
   - JWT Secret Key — раз в 3-6 месяцев
   - YooKassa — при подозрении на утечку

4. **Храните ключи в безопасном месте:**
   - Используйте менеджеры паролей (1Password, LastPass)
   - Или секреты в облачных платформах (Vercel, AWS Secrets Manager)

5. **Ограничьте доступ к ключам:**
   - Только необходимые люди должны знать ключи
   - Используйте переменные окружения на сервере, а не файлы
