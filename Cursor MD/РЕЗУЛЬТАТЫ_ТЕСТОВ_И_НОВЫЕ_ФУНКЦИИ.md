## 🆕 Новые функции

### 1. Модуль аналитики (`analytics.py`)

**Функции:**
- `get_user_stats()` - статистика пользователя
- `get_system_stats()` - общая статистика системы
- `get_analyses_timeline()` - временная линия анализов
- `get_popular_industries()` - популярные отрасли
- `get_average_scores()` - средние оценки по отраслям

**API эндпоинты:**
- `GET /api/analytics/user/{user_id}` - статистика пользователя
- `GET /api/analytics/system` - системная аналитика (только админ)
- `GET /api/analytics/timeline` - временная линия
- `GET /api/analytics/popular-industries` - популярные отрасли
- `GET /api/analytics/average-scores` - средние оценки

**Метрики:**
- Количество пользователей
- Активные пользователи (30 дней)
- Всего анализов
- Распределение по тарифам
- Распределение по отраслям
- Средние оценки
