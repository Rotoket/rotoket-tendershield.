# 🔧 Исправление проблемы анализа документов

## Проблема
Анализ документов возвращает ошибку 500.

## Внесенные исправления

### 1. Улучшена обработка ошибок
- ✅ Добавлена проверка на пустой ответ от Ollama
- ✅ Улучшено логирование ошибок парсинга JSON
- ✅ Добавлен детальный traceback для диагностики

### 2. Улучшен парсинг JSON
- ✅ Проверка наличия JSON в ответе
- ✅ Детальное логирование проблемных фрагментов
- ✅ Улучшен fallback при ошибках парсинга

### 3. Улучшена обработка исключений
- ✅ HTTPException пробрасываются как есть
- ✅ Другие исключения логируются с traceback
- ✅ Возвращается понятное сообщение об ошибке

## Как проверить

1. Запустите backend с логированием:
```bash
uvicorn main:app --reload --log-level debug
```

2. Попробуйте проанализировать документ

3. Проверьте логи в консоли - там будет детальная информация об ошибке

## Возможные причины ошибки 500

1. **Ollama не отвечает** - проверьте `ollama serve`
2. **Модель не загружена** - выполните `ollama pull qwen2.5:0.5b`
3. **Невалидный JSON от LLM** - проверьте логи
4. **Ошибка чтения файла** - проверьте формат файла
5. **Ошибка БД** - проверьте подключение к БД

## Следующие шаги

Если проблема сохраняется:
1. Проверьте логи backend при анализе
2. Убедитесь, что Ollama запущен и модель доступна
3. Проверьте формат загружаемого файла
4. Проверьте подключение к БД
