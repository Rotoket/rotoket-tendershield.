# 🔧 Быстрое решение: Ошибка анализа документа

## Проблема

Ошибка: `Failed to connect to Ollama` или `[WinError 10061] Подключение не установлено`

**Причина:** Ollama не запущен или не доступен по адресу `http://localhost:11434`

---

## ✅ Решение (Windows)

### Шаг 1: Запустите Ollama

**Вариант A: Через меню Пуск**
1. Найдите "Ollama" в меню Пуск
2. Запустите приложение
3. Дождитесь появления иконки Ollama в трее (правый нижний угол)

**Вариант B: Через командную строку**
```powershell
# Попробуйте запустить как сервис
ollama serve
```

**Вариант C: Если Ollama не установлен**
1. Скачайте установщик: https://ollama.ai/download
2. Установите Ollama
3. После установки Ollama должен запуститься автоматически

### Шаг 2: Проверьте, что Ollama запущен

Откройте новый терминал и проверьте:
```powershell
ollama list
```

Должен появиться список моделей (может быть пустым).

### Шаг 3: Установите модель (если её нет)

```powershell
# Легкая модель (рекомендуется для начала):
ollama pull qwen2.5:0.5b

# Или более мощная модель:
ollama pull qwen2.5-coder:7b
```

### Шаг 4: Проверьте подключение из проекта

```powershell
cd backend
python check_ollama.py
```

Должно появиться: `✅ Все проверки пройдены! Ollama готов к работе.`

### Шаг 5: Перезапустите backend

После запуска Ollama:
1. Остановите backend (Ctrl+C)
2. Запустите снова:
   ```powershell
   cd backend
   uvicorn main:app --reload
   ```

## 🔍 Диагностика

### Проверка доступности Ollama

Откройте в браузере: http://localhost:11434

Должна открыться страница или вернуться JSON-ответ.

### Проверка через curl (если установлен)

```powershell
curl http://localhost:11434/api/tags
```

Должен вернуться список моделей в формате JSON.

## ⚠️ Частые проблемы

### Проблема 1: Ollama не запускается

**Решение:**
1. Перезагрузите компьютер
2. Проверьте, не блокирует ли антивирус Ollama
3. Попробуйте запустить от имени администратора

### Проблема 2: Порт 11434 занят

**Решение:**
1. Проверьте, что порт свободен:
   ```powershell
   netstat -ano | findstr :11434
   ```
2. Если порт занят другим процессом, завершите его или измените порт в `backend/.env`:
   ```env
   TENDER_OLLAMA_BASE_URL=http://localhost:11435
   ```
3. И запустите Ollama на другом порту:
   ```powershell
   OLLAMA_HOST=localhost:11435 ollama serve
   ```

### Проблема 3: Модель не загружается

**Решение:**
1. Убедитесь, что есть свободное место на диске (модели занимают несколько GB)
2. Проверьте интернет-соединение
3. Попробуйте другую модель (более легкую)

## 📝 После решения

После того как Ollama запущен и модель установлена, анализ документов должен работать.

**Проверьте:**
1. ✅ Ollama запущен (иконка в трее)
2. ✅ Модель установлена (`ollama list` показывает модель)
3. ✅ Backend перезапущен
4. ✅ Анализ работает в интерфейсе

---

## 🆘 Если ничего не помогает

1. Проверьте логи backend для подробностей об ошибке
2. Убедитесь, что в `backend/.env` правильно указан URL:
   ```env
   TENDER_OLLAMA_BASE_URL=http://localhost:11434
   ```
3. Попробуйте использовать альтернативный способ анализа (если есть fallback в системе)
