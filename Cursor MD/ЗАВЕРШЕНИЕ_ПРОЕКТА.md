## 📦 Установка и запуск

### Все зависимости установлены:
- ✅ Python 3.12+ с виртуальным окружением
- ✅ Node.js 18+ с npm пакетами
- ✅ Все Python пакеты из requirements.txt
- ✅ Все npm пакеты из package.json

### Для запуска:

**Вариант 1: Скрипты (Windows)**
```bash
# PowerShell
.\start.ps1

# Или Batch
start.bat
```

**Вариант 2: Вручную**
```bash
# Backend
cd backend
venv\Scripts\activate
uvicorn main:app --reload

# Frontend (новый терминал)
cd frontend
npm run dev
```
