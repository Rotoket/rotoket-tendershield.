# План редизайна: Cyberpunk Corporate Style

## Дата создания: 04.12.2025
## Ветка: `feature/cyberpunk-redesign`

---

## 🎨 Концепция дизайна

**Стиль:** Cyberpunk Corporate
- Темный фон (не белый!)
- Тонкие границы
- Эффекты свечения при наведении
- Четкая визуальная иерархия: что хорошо / что плохо

---

## 📋 Цветовая палитра

### Фоны
- Основной фон: `#1a1f2e`
- Вторичный фон: `#2a3441`
- Карточки: `#020617` / `#0f1419`

### Статусы
- Синий (информация): `#002648`
- Желтый (предупреждение): `#facc15`
- Красный (критично): `#ff4444`
- Зеленый (OK): `#00e648` / `#10b981`

### Границы
- Стандартная: `#2a3441` / `#1f2937`
- Активная: `#00d4ff` (с эффектом свечения)
- Критическая: `#ff4444` (с эффектом свечения)

---

## 🎯 Ключевые компоненты для переделки

### 1. Financial X-ray Grid
**Сетка 2x4 или 4x1** с карточками:
- НМЦК (Initial Maximum Contract Price)
- Маржа (Margin)
- Обеспечение (Security)
- Аванс (Advance)

**Стиль карточек:**
- Фон: `#1a1f2e`
- Граница: `#2a3441`
- При наведении: эффект свечения `#00d4ff`

### 2. Red Flags (Риски)
**Список карточек:**
- Критические риски: красная граница + подсветка
- Цитаты из документа: курсив, серый цвет
- Закон: ссылка с эффектом свечения при наведении

### 3. TenderDetail Screen
**Новый экран для детального просмотра:**
- Структурированная информация
- Визуальная индикация статусов
- Четкое разделение: хорошо / плохо
