## 🚀 Быстрый старт

### 1. Установите зависимости

```bash
cd backend
pip install -r requirements.txt
```

### 2. Настройте PostgreSQL

**Docker (рекомендуется):**
```bash
docker run --name tender-db \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=tender_shield \
  -p 5432:5432 \
  -d postgres:15
```

### 3. Создайте `.env` файл

```env
TENDER_DB_USER=postgres
TENDER_DB_PASSWORD=postgres
TENDER_DB_HOST=localhost
TENDER_DB_PORT=5432
TENDER_DB_NAME=tender_shield
TENDER_SECRET_KEY=your-super-secret-key-min-32-chars
```

### 4. Инициализируйте БД

```bash
python init_db.py
```

### 5. Запустите сервер

```bash
uvicorn main:app --reload
```

### 6. Протестируйте API

```bash
# Регистрация
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"test123","name":"Тест"}'

# Вход
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"test123"}'
```

## ⚠️ Важные замечания

1. **SECRET_KEY**: Обязательно измените `TENDER_SECRET_KEY` в продакшене на случайную строку минимум 32 символа!

2. **БД опциональна**: Система работает и без БД (для обратной совместимости), но функциональность ограничена.

3. **Миграции**: Используйте Alembic для управления схемой БД. Не редактируйте таблицы вручную!

4. **Безопасность**: В продакшене обязательно:
   - Используйте HTTPS
   - Настройте CORS правильно
   - Используйте сильный SECRET_KEY
   - Настройте rate limiting
   - Шифруйте чувствительные данные
