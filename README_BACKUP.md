# 💾 ИНСТРУКЦИЯ ПО СОХРАНЕНИЮ ПРОЕКТА

## ⚡ БЫСТРЫЙ СТАРТ

### Перед переустановкой Windows:

1. **Запустите скрипт бэкапа:**
   ```powershell
   .\backup_script.ps1
   ```
   Это создаст полную резервную копию в `D:\Backup\`

2. **Закоммитьте все изменения в Git:**
   ```bash
   git add .
   git commit -m "Backup before Windows reinstall"
   git push
   ```

3. **Проверьте, что файл `backend\.env` сохранен** (он содержит секретные ключи!)

### После переустановки Windows:

Следуйте инструкциям в файле `QUICK_BACKUP.md` или подробной инструкции в `BACKUP_AND_RESTORE.md`

---

## 📚 ДОКУМЕНТАЦИЯ

## ⚠️ ВАЖНО

1. **Файл `.env`** содержит секретные ключи - сохраните его отдельно и безопасно!
2. **База данных** - если есть важные данные, экспортируйте их через скрипт
3. **Ollama модели** - можно скачать заново, но это займет время
