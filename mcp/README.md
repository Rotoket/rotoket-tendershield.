# MCP в Tender Shield Pro
В этой папке собрана документация и шаблоны для работы с MCP (Model Context Protocol) в Cursor.

Цель: чтобы любой разработчик мог быстро поднять MCP-набор, не копаясь в «архивных» файлах, и при этом не утащил секреты в репозиторий.

## Быстрый старт (Cursor)
1. Скопируйте шаблон конфига из `mcp/templates/cursor.mcp.example.json`.
2. Вставьте его в локальный файл Cursor:
   - Windows: `%APPDATA%\Cursor\mcp.json`
3. Замените плейсхолдеры (например, `CHANGE_ME`) на свои значения.
4. Перезапустите Cursor.

Важно: `mcp.json` — локальная машина-разработка, не храните его в репозитории (особенно с паролями).

## Какие MCP-серверы используем
Набор, который считается «базовым» для этого проекта:
- `sequential-thinking` — структурирование задач и планирование
- `context7` — актуальная документация (когда нужна свежая инфа)
- `filesystem` — создание/редактирование файлов
- `git` — операции с git
- `docker` — управление контейнерами
- `postgres` — запросы к БД и миграции
- `code-quality` — тесты/линтеры
- `npm` — зависимости и скрипты
- `browser` — браузер/скриншоты
- `playwright` — E2E и браузерная автоматизация

## Безопасность и правила работы
См. `mcp/SECURITY.md`.

Коротко:
- любые действия, которые могут что-то удалить/переписать/запушить — только после явного подтверждения
- секреты (пароли, токены) нельзя коммитить ни в `.env`, ни в `mcp.json`

## Структура папки
- `mcp/templates/` — шаблоны (без секретов)
- `mcp/1/`, `mcp/2/` — «наследие» (старые инструкции/пакеты; читать только при необходимости)

## Про «память» проекта
Файл `backend/.mcp-memory.json` — это не конфиг MCP-серверов. Это data-файл со справочными заготовками (риски/нарушения/рекомендации), которые используются в логике анализа.
Подробнее: `backend/MCP_MEMORY.md`.
