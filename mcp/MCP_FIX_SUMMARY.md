## 📋 ЧТО ДЕЛАТЬ ДАЛЬШЕ

### 1. Перезагрузи Cursor

**ВАЖНО:** Cursor нужно перезагрузить после обновления `mcp.json`!

1. Закрой Cursor полностью (Файл → Выход)
2. Открой Cursor снова
3. Подожди 10-20 секунд (серверы загружаются)

### 2. Проверь серверы

1. Открой: **Settings** → **Tools & MCP** → **MCP Servers**
2. Должны быть видны все **13 серверов:**
   - sequential-thinking
   - context7
   - playwright
   - filesystem
   - git
   - postgres
   - pandoc
   - xlsx
   - python
   - docker
   - browser
   - code-quality
   - npm

3. Проверь статус каждого:
   - ✅ Зелёный = работает
   - ❌ Красный/Error = есть проблема

### 3. Если серверы всё ещё показывают ошибки

Для каждого сервера с ошибкой:

1. Нажми **"Show Output"**
2. Скопируй ошибку
3. Исправь согласно `MCP_FIX_WINDOWS.md`

**Типичные ошибки:**

- **`'npx' is not recognized`**
  - Решение: Перезагрузи компьютер
  
- **`Connection refused`** (для postgres)
  - Решение: Проверь, что PostgreSQL запущен
  
- **`ENOENT: no such file`**
  - Решение: Проверь JSON синтаксис в `mcp.json`
