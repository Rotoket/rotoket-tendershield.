#### 2.3. Сроки подачи заявок

**Требование 44-ФЗ:**
- Минимальный срок подачи заявок зависит от НМЦК
- Для НМЦК > 3 млн руб. — не менее 15 дней
- Для НМЦК < 3 млн руб. — не менее 7 дней

**Проверка:**
- ✅ Срок соответствует требованиям → OK
- ❌ Срок меньше минимального → **DEAL BREAKER**
- ⚠️ Срок на границе → предупреждение

**Код:**
```python
# В extractors/tender_passport_extractor.py добавить:
def check_44fz_deadline_compliance(nmck: float, deadline: date, publication_date: date) -> dict:
    """Проверка соответствия срока подачи заявок требованиям 44-ФЗ"""
    days_until_deadline = (deadline - publication_date).days
    
    if nmck >= 3_000_000:
        min_days = 15
    else:
        min_days = 7
    
    if days_until_deadline < min_days:
        return {
            "compliant": False,
            "severity": "HIGH",
            "message": f"Нарушение 44-ФЗ: срок подачи заявок ({days_until_deadline} дней) меньше минимального ({min_days} дней)"
        }
    return {"compliant": True}
```
