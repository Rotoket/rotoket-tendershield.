# Tender Shield Pro - Frontend

Frontend-приложение для анализа тендерной документации. Разработано на React + TypeScript + Vite.

## Технологии

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Tailwind CSS** - стилизация
- **Lucide React** - иконки
- **Vitest** - тестирование

## Установка и запуск

### Предварительные требования

- Node.js 18+ 
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Запуск тестов

```bash
npm test
```

Для watch-режима:
```bash
npm run test:watch
```

## Основные экраны

### Analyzer
Анализ одного документа тендерной документации. Показывает:
- Индекс безопасности и вердикт
- Паспорт тендера
- Глубокий аудит (чек-лист)
- Хаб-дашборд с ключевой информацией
- Чат с AI-помощником

### ComplexAudit
Комплексный анализ пакета документов. Показывает:
- Общую оценку пакета
- Список документов с оценками
- Глобальные риски по пакету
- Детальный анализ выбранного документа

### Calculator
Калькулятор маржинальности с учётом рисков.

### DocumentGenerator
Генерация черновиков документов:
- Протокол разногласий
- Жалоба в ФАС

### KnowledgeView
База знаний по законодательству (44-ФЗ, 223-ФЗ, 135-ФЗ, 152-ФЗ).

### HistoryView
История проведённых анализов.

## Конфигурация

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите URL backend API.

## Логирование

Все важные действия пользователя логируются через `src/utils/logger.ts`:
- Загрузка файлов
- Запуск анализа
- Генерация документов
- Действия с калькулятором

## Тестирование

Тесты написаны с использованием Vitest и Testing Library. Находятся рядом с тестируемыми модулями:
- `src/utils/logger.test.ts`
- `src/utils/docDrafts.test.ts`
- `src/utils/packageReport.test.ts`

## Разработка

### Правила кодирования

- Весь пользовательский интерфейс только на русском языке
- Все компоненты должны использовать TypeScript типы из `src/types.ts`
- Важные действия должны логироваться через `logEvent`
- Компоненты должны быть покрыты тестами по возможности

### Добавление нового экрана

1. Добавьте новый `AppView` в `src/types.ts`
2. Создайте компонент в `src/components/`
3. Добавьте маршрут в `src/App.tsx`
4. Добавьте навигацию в `src/components/Sidebar.tsx`
