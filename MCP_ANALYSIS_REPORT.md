## 🎯 КАСТОМНЫЙ СЕРВЕР: pandoc_mcp.py

### Описание:
Собственный Python MCP сервер для конвертации документов тендеров.

### Функции:

#### 1. `convert_to_markdown(file_path: str, output_path: Optional[str] = None) -> dict`
- Конвертирует .docx в Markdown
- Возвращает: `{success, output_path, content, error}`
- Поддерживает: DOCX, DOC, XLSX, XLS, ODT, RTF, HTML

#### 2. `extract_nmck_iun(file_path: str) -> dict`
- Автоматически извлекает НМЦК и ИУН
- Возвращает: `{success, nmck, nmck_numeric, iun, markdown_path, error}`
- Использует regex паттерны для поиска

### Преимущества:
- ✅ Не зависит от npm пакетов
- ✅ Работает на любом сервере с Python
- ✅ Легко расширяется
- ✅ Интегрирован в backend автоматически
