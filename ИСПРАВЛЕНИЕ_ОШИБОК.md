# 🔧 Исправление ошибок Backend и Frontend

## ✅ Исправлено

### 1. Backend: Ошибка кодировки PostgreSQL
**Проблема:** `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xc2`

**Решение:** 
- Улучшена обработка кодировки в `database.py`
- Добавлена защита от не-UTF-8 символов в пароле и имени БД
- Добавлен автоматический fallback на SQLite при проблемах с кодировкой

### 2. Frontend: Проверка скрипта "dev"
**Проверено:** Скрипт `"dev": "vite"` присутствует в `package.json`

## 🔍 Диагностика

### Проверка Backend:

```powershell
# Проверьте, что backend запущен
netstat -ano | findstr ":8000"

# Проверьте API
curl.exe http://localhost:8000/api/health
```

Должен вернуться JSON с `"status": "ok"`

### Проверка Frontend:

```powershell
# Проверьте, что frontend запущен
netstat -ano | findstr ":5173"

# Проверьте package.json
cd frontend
Get-Content package.json | Select-String "dev"
```

Должно показать: `"dev": "vite"`

## ⚠️ Если проблемы сохраняются

### Backend (кодировка):

1. **Используйте SQLite вместо PostgreSQL:**
   - Backend автоматически переключится на SQLite
   - Это нормально для разработки
   - Все функции работают с SQLite

2. **Или исправьте кодировку PostgreSQL:**
   - Убедитесь, что пароль БД содержит только ASCII символы
   - Или используйте переменные окружения:
     ```powershell
     $env:TENDER_DB_PASSWORD="postgres"
     ```

### Frontend (скрипт):

1. **Проверьте кодировку package.json:**
   ```powershell
   # Убедитесь, что файл в UTF-8
   [System.IO.File]::ReadAllText("package.json", [System.Text.Encoding]::UTF8)
   ```

2. **Попробуйте запустить напрямую:**
   ```powershell
   npx vite
   ```

3. **Переустановите зависимости:**
   ```powershell
   Remove-Item -Recurse -Force node_modules
   npm install
   npm run dev
   ```
